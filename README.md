# LED Data Comparison

ClearLED product-intelligence workspace with a separated sign-in, application selector, and LED comparison tool.

## Pages

- `index.html` — workspace sign-in
- `applications.html` — authenticated application selector
- `comparison.html` — existing LED product comparison

The current sign-in is a front-end preview only. It accepts any valid email and a password of at least six characters. Connect a real identity provider before production use.
